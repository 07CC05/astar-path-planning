# 数据结构课程设计报告框架 — A* 路径规划可视化

> 适用：向苏畅老师答辩。命题性质：自主选题（难度 1.2–1.3）。
> 核心主张：这是一份**数据结构作业**，不是小游戏，每一步都能对回课程知识点。

## 摘要（约 200 字）
以网格图为对象，实现 A*、Dijkstra、BFS、贪心最佳优先四种路径搜索算法；自制二叉最小堆作为优先队列，比较不同启发函数与 open list 实现的性能。给出正确性验证（1066 项断言通过）与规模实验（512×512 下二叉堆较线性扫描快约 6 倍）。关键词：图、优先队列、二叉堆、启发式搜索、A*。

## 第 1 章 选题背景与目标
1.1 选题缘由：A* 是"图 + 优先队列"的典型综合应用，也是自主选题中能同时体现数据结构功底与工程价值的题目。
1.2 题目要求与难度定位（自主选题，1.2–1.3）。
1.3 目标与范围：**只做步骤 1–2**（四算法实现、网格可视化、启发函数对比、动态障碍）；ROS2/Gazebo、竞赛报名属课外，不纳入课程设计（对应"自选题纪律②"）。

## 第 2 章 需求分析
2.1 功能需求：地图建模、四类搜索、启发函数切换、动态障碍重规划、结果可视化、算法横向对比。
2.2 数据需求：网格图（顶点=格子，边=邻接）、起终点、障碍集合。
2.3 性能需求：大规模网格下 open list 应高效；记录扩展节点数作为效率观测量。
2.4 约束：C++17、零第三方依赖、结果可复现（固定随机种子）。

## 第 3 章 数据结构设计（**答辩重点**）
3.1 图的存储：网格用一维数组 `Grid[y*cols+x]`，即邻接矩阵的紧凑表示；4/8 邻接方向表。
3.2 优先队列：自制二叉最小堆 `MinHeap`，数组存储完全二叉树，push 上滤 / pop 下滤 O(log n)；元素 `{f,h,idx}`，f 相同按 h 排序（tie-break）。强调**未使用 STL priority_queue**。
3.3 集合与辅助结构：`closed` 用 `Uint8Array` 直接寻址（等价哈希集合，O(1) 判重）；`cameFrom` 回溯路径；`gScore` 记录代价。
3.4 BFS 的 FIFO 队列（`std::deque`）。
3.5 递归：递归分割迷宫生成（`divide` 函数）。
> 本章配"知识点映射表"（见 02_知识点映射表.md），是自选题不被判跑题的关键。

## 第 4 章 算法设计与实现
4.1 统一搜索框架与伪代码。
4.2 四种算法的优先级定义：
   - Dijkstra：f = g（无启发，保证最优）
   - BFS：FIFO 队列，无权图最短路
   - A*：f = g + h（h 可采纳且一致 → 最优）
   - 贪心最佳优先：f = h（不保证最优）
4.3 启发函数：曼哈顿 |Δx|+|Δy|、欧氏 √(Δx²+Δy²)、加权 2×(曼哈顿)。
4.4 动态障碍重规划：完整重规划流程与代价说明（扩展数可能增减；增量式 LPA*/D* Lite 超出范围）。
4.5 正确性保证：lazy-deletion 判重、不穿墙角、不可达判定。

## 第 5 章 测试与实验（**数据支撑**）
5.1 正确性测试：6 类断言、1066 项通过（堆性质、路径连通、最优性一致、A*≤Dijkstra、加权权衡、不可达）。
5.2 四算法横向对比（同一地图同一起终点）：
   - 迷宫 41×27 seed=42：A* 扩展 116，Dijkstra 438，BFS 430，贪心 187；四者步数均 62。
   - 随机 31×21 seed=7：A* 扩展 71，Dijkstra 814，BFS 804；步数均 62（贪心加权时 50 步，次优）。
5.3 规模实验（二叉堆 vs 线性扫描）：64² 1.09× → 128² 1.17× → 256² 3.63× → 512² 6.55×，验证 O(log n) 优势随规模放大。
5.4 可视化结果：ASCII 终端图与 SVG 路径图（见 output/）。
5.5 结果分析：A* 用启发把搜索"拉向"终点，扩展数约为 Dijkstra 的 1/4～1/11；加权更快但可能次优。

## 第 6 章 复杂度分析
6.1 时间：BFS O(V+E)；Dijkstra/A*（二叉堆）O((V+E)logV)；线性扫描 open list O(V²)。
6.2 空间：均 O(V)。
6.3 工程权衡：lazy-deletion 用空间换实现简洁，避免 decrease-key。

## 第 7 章 结论与展望
7.1 结论：四算法正确性得到验证；自制二叉堆带来显著规模收益；A* 在最优性与效率间取得平衡。
7.2 局限：完整重规划不复用旧信息；8 邻接对角代价为近似。
7.3 展望（课外）：ROS2+Gazebo 仿真小车、增量式路径搜索、竞赛/大创。
