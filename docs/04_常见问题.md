# 常见问题与应对思路（浓缩版）

> 详细版见 `03_答辩预案.md`（24 问）。本文件列出最可能被追问、且最容易被答错的 6 个问题。

## 1. "这算数据结构作业吗？会不会被判跑题？"
**应对**：立刻展示知识点映射表（02 号文件）。核心论点——图（网格建模）、优先队列（自制二叉堆）、集合（closed 判重）、队列（BFS）、排序（取最小）、递归（迷宫）六大知识点全部落地，每一行都有源码位置。可视化只是验证手段。

## 2. "A* 凭什么比 Dijkstra 快？"
**应对**：Dijkstra 按 g 扩展，像水波均匀扩散；A* 按 g+h 扩展，h 把搜索"拉向"终点。实测同一地图：A* 扩展 116，Dijkstra 438，步数同为 62——结果一样优，但 A* 少探索约 3/4 的节点。

## 3. "为什么不用现成的优先队列？"
**应对**：课程要求掌握结构内部实现。自写二叉堆才能控制 tie-break、才能讲清上滤/下滤与 O(log n)；调用 STL 无法证明能力。补充：规模实验证明选堆而非线性扫描有 6.55× 的实际收益。

## 4. "贪心最优优先和 A* 有什么区别？"
**应对**：贪心只看 h（f=h），不考虑已走代价，所以快但不保证最优——迷宫 seed=3 时走 98 步，A* 62 步。A* 用 f=g+h 兼顾代价与启发，在可采纳启发下最优。

## 5. "动态障碍那栏，重规划后扩展数怎么变少了？"
**应对**：这是完整重规划的正常现象。障碍挡路的同时也封住了一些原本要探索的死路，所以扩展数可能增、减或不变。若要让开销单调可控，需增量式算法 LPA*/D* Lite，超出课程范围，属展望。

## 6. "为什么范围只做到这里？"
**应对**：课程设计只装步骤 1–2（四算法 + 可视化 + 启发对比 + 动态障碍），对应三条纪律里的"范围切分"。ROS2/Gazebo 与竞赛是步骤 3–4，留课外，避免踩评分口径——这是数据结构课，不是机器人课。
